# Raka-Sang-Penjelajah-Waktu-Tiga-Hari-Menuju-Merdeka

Game 2D side-scrolling platformer bergenre action-adventure yang mengangkat tema sejarah perjuangan kemerdekaan Indonesia. Game ini menceritakan perjalanan Raka Bumi, seorang pemuda magang dari masa depan yang secara tidak sengaja melakukan perjalanan waktu ke masa menjelang Proklamasi Kemerdekaan Indonesia pada 17 Agustus 1945.

Dalam petualangannya, Raka harus menghadapi berbagai tantangan, melawan tentara Jepang, berinteraksi dengan tokoh-tokoh sejarah dan masyarakat, serta menyelesaikan berbagai misi dan mini-game, termasuk puzzle penyetelan radio. Melalui perpaduan gameplay, cerita, dan unsur sejarah, game ini bertujuan memberikan pengalaman bermain yang menghibur sekaligus memperkenalkan kembali peristiwa-peristiwa penting menjelang kemerdekaan Indonesia.

Dikembangkan menggunakan Unity.
